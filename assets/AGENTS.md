## Overview

This is a static website with English phrases that help me to use this collection as a reference in the future, since my English skill is not good.

My aim is to utilize these as a reference to become better at communication, because the phrases that are mostly used or commonly used in communication, I have combined into one single collection.

## Tech Stack & Requirements

For this application, the tech stack will be:

- HTML
- CSS (omit Tailwind CSS and use just plain CSS)
- JavaScript
- local SVG icon (because I will load this application locally)
- Lucid icons

I also want:

- micro-animation
- a sidebar for the desktop screen
- a sidebar mobile menu for the mobile screen
- a top fixed search bar that lets me filter the phrases by typing

The typed characters or text should be matched to the three columns values available in the phrase data. When rendering the phrases in the UI, omit the phonetic form of the text. Only keep Bangla and English phrases.

I want a cozy, cool, good-looking, soft user interface, not a generic user interface. Use colors by thinking of yourself as a senior UI/UX designer. Also, don't forget to implement a dark and light theme feature and utilize a CSS hack by using root variables and `.dark` class variables for dark and light themes.

Write modular code by splitting files instead of creating one massive file.
