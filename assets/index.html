∞ Honest limits

      
What this template cannot do without extra dependencies or work.

      
    
        
  • Background work — no Service/ForegroundService wiring beyond a raw service class. Would need manifest entries + startForegroundService on API 26+.
    • 
        
  • Secure origin — this demo runs on file://. Anything gated on a real https origin (some newer APIs, service workers, navigator.clipboard) needs WebViewAssetLoader from androidx.webkit, i.e. a Gradle dependency.
    • 
        
  • Type-safe bridge — addJavascriptInterface is string-based and sync-only. Typed, async, promise-based bridges need androidx.webkit WebMessageListener or manual callback plumbing (see card 10).
    • 
        
  • Biometrics — BiometricPrompt lives in androidx.biometric.
    • 
        
  • SQLite / Room — SQLite is in the SDK, but a clean ORM is a dependency.
    • 
        
  • Contacts, Bluetooth LE, NFC — SDK APIs exist, but each needs manifest permissions + runtime handling + multi-screen UI. Possible, tedious.
    • 
        
  • In-app updates, billing, ads, crash reporting — all Play/Gradle dependencies. Not happening dep-free.
    • 
        
  • Photo capture via <input capture> — needs a custom ACTION_IMAGE_CAPTURE intent + FileProvider. This demo only wires ACTION_GET_CONTENT.
    • 
        
  • Kotlin-only libraries — callable from Java, but the template stays Java-only on purpose.
    • 
        
  • Debugger / logcat — no Android Studio here. Use chrome://inspect for the web layer and adb logcat for Java.
