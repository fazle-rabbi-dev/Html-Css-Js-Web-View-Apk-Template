## What it does

Standby Clock keeps your phone as a bedside clock with dimmed, ambient display. Adjust brightness, pick 12/24h, and let it run all night without burning the screen. Great for nightstands and desk setups.

## Get an APK (`for devs`)

1. Fork / clone this repo.
2. Push to GitHub → the **Build APK** workflow runs automatically.
3. Go to **Actions** → latest run → download the **{{APP_NAME}}** artifact.
4. Install the APK on your Android device.

> Make sure **Play Protect is turned off** before installing.

## 🛠️ Built with
